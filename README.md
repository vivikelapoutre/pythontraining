# Example project

This is an example project for the exercises of the Data Science basics course. It contains a few files that can be used for practicing running code, cleaning code and testing it.

## Clean code

The standard styleguide for Python is PEP-8, however, it is allowed to decide to do something differently for a good reason.

#### Answers to excercises

In the file ```operators.py``` did you find:
- the comment on line 4?
- all 4 functions?
- did you remove superfluous spaces around operatores?
- did you remove whitespace at the end of the line?
- did you remove the unused import?
- did you rename the functions to snake case (and maybe a better name)?
- in the function ```the_best_function```
  - did you reformat (and maybe rewrite) the doc-string?
  - did you notice the indentation is only two spaces?
  - did you notice the function doesn't do what the doc-string says it does?
- in the function ```FunctionThatCan_do_everything```:
  - what happens to variable ```c```? is it ever read?
  - are there other unused variables?
  - did you notice the variable named ```number``` is not a number?
  - did you notice the ```== True```? did you change it to ```is True```? did you remove it?
  - did you remove all the pointless comments?
  - did you notice that it doesn't go anywhere if ```a``` is equal to 10?
